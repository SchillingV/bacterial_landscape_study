## bacterial_landscape_study
This repository contains the metadata to the PRIDE data set: PXD079235
https://www.ebi.ac.uk/pride/archive/projects/PXD079235

# Description
Liquid chromatography-tandem mass spectrometry (LC-MS/MS) utilizing Data-Independent Acquisition (DIA) has emerged as a transformative tool for microbial proteomics, offering the speed and analytical depth required for large-scale bacterial identification. In this work, we present a comprehensive DIA dataset covering over 100 unique bacterial species from more than 40 genera, acquired using the diaPASEF method at three acquisition speeds: 100, 200, and 500 samples per day (SPD). For each sample, an additional data-dependent acquisition (DDA) run at 100 SPD was performed to support peptide identification and spectral library construction. In total, the dataset comprises 199 bacterial samples, each represented across all DIA and DDA acquisition modes. This dataset supports applications such as taxonomic classification, benchmarking of proteomics workflows, and evaluating how acquisition speed influences proteome coverage. It provides a basis for balancing throughput and analytical depth in large-scale proteomics studies. We further anticipate that it will support the development of machine learning approaches in computational proteomics and can help for improved bacteria characterization and identification.
